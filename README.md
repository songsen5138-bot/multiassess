# 다면평가 편하샘

학교 **다면평가자**가 동료 교원의 순위를 정하면 점수를 자동으로 만들어 주고(정성평가), 선생님들이 **정량평가 자기평가서**를 작성해 한글 파일로 내려받게 하는 프로그램입니다. 관리자는 명단을 넣어 배포용 파일을 만들어 보냅니다.
엑셀 매크로(xlsm)로 쓰던 '다면평가 평가자용 점수 생성기'를 웹 브라우저에서 돌아가는 HTML 파일 하나로 옮겼습니다.

> 이 저장소는 **프로그램이 어떻게 운영되는지 보여 주는 체험용 샘플**입니다.
> 들어 있는 교원 이름은 모두 **가짜 자료(역사 인물)** 이며, 실제 평가 자료는 어디에도 올리지 않습니다.

## 체험해 보기

**바로 체험: https://songsen5138-bot.github.io/multiassess/demo.html**

내려받았다면 `demo.html`을 브라우저(크롬·엣지)로 열면 됩니다.

- 로그인 없이 바로 열립니다.
- 가짜 자료: 정규교사 36명, 기간제교사 6명, 다면평가자 8명
- 다면평가자 한 명이 정규교사 순위를 반쯤 정한 모습으로 시작합니다.
- 체험하며 바꾼 내용은 위쪽 **[체험 자료 처음 상태로]** 를 누르면 되돌아갑니다.
- `테스트 자료/가짜 정성평가 배포용 파일 (2026.11.18까지).html`은 다면평가자 화면을 볼 수 있는 시험용 배포 파일입니다. (이름: 을지문덕, 계백, 김유신, 원효, 장보고, 왕건, 강감찬, 의천)
- `테스트 자료/가짜 제출자료 배포용 파일 (2026.11.18까지).html`은 선생님이 정량평가 자기평가서를 먼저 입력하고 교사 자기실적평가서를 이어서 작성하는 화면입니다. ("계백"으로 들어가면 미리 채운 값을 볼 수 있음)
- `테스트 자료/가짜 정량평가 자기평가서/` 폴더에는 가짜 선생님 5명의 정량평가 자기평가서(hwpx)가 있습니다. [정량평가 결과 파일 만들기]에 이 폴더를 넣어 볼 수 있습니다.
- 두 시험용 배포 파일 모두 [접근자로 들어가기]에 아이디 `시험`, 비밀번호 `1234`로 들어가 볼 수 있습니다.

## 운영 흐름

```
관리자 (다면평가 편하샘.html)            다면평가자 (배포용 파일)
─────────────────────────────            ──────────────────────
1. 다면평가 기본 세팅
   · 기본 정보: 학년도, 학교 이름, 학교급
   · 평가 대상자 명단 (구분별: 정규교사, 기간제교사 …, 엑셀·한글 파일 불러오기)
   · 다면평가자 명단
   정성평가 배포 파일 만들기
   · 사용 기한
        │  학교 한 곳에 하나의 배포용 HTML 파일
        └─────────────────────────────▶ 2. 배포용 파일 열기
                                           · 안내 사항 확인 + 자기 이름으로 들어가기
                                        3. 순위 정하기
                                           · 본인을 뺀 평가 대상자를 끌어다 순위 칸에 놓기
                                           · 점수 다시 만들기, 총점 직접 고치기
                                        4. 최종 점수표
                                           · 다면평가자용 엑셀 파일이 있으면 그 파일에 점수를 채움
                                           · 엑셀 파일 내려받아 제출
        ┌─────────────────────────────── 제출
5. 제출자료 배포 파일 만들기              선생님 (제출자료 배포용 파일)
   · 사용 기한                           ──────────────────────────
        └─────────────────────────────▶ · 자기 이름으로 들어가기
                                        · ① 정량평가 자기평가서: 실적 입력 → 점수 자동 계산
                                        · ② 교사 자기실적평가서: 정량평가 값·기본 세팅 자료가 들어감
                                        · 자기실적평가서를 마치면 한글(hwpx) 2개를 한꺼번에 내려받아 제출
6. 백업/초기화, 관리자 관리
```

## 교사 자기실적평가서

- 양식: `assets/template/self-template.hwpx` ([서식 2] 교사 자기실적평가서)
- [제출자료 배포 파일 만들기]: 정량평가 자기평가서와 한 배포 파일. 정량평가를 다 입력해야 자기실적평가서로 넘어감 (수업시간·수업공개·상담 실적이 자기실적평가서로 들어감)
- 미리보기: 오른쪽 [1 정량평가 자기평가서 작성] [2 교사 자기실적평가서 작성] 단추로 번갈아 봄
- 입력: 직위, 4. 평가자 기초 자료 10칸, 5. 자기실적 평가 9항목(한 줄에 하나씩 → 한글 파일에 줄마다 '- '), 자기 평가 종합 상황(만족·보통·미흡)
- 한글 파일: 고른 만족·보통·미흡은 네모 테두리, 성명·작성자 이름을 채움. 표는 글자처럼 취급 해제·쪽 경계에서 나눔이라 내용이 길면 다음 쪽으로 이어짐

## 정량평가 결과 파일 만들기

- 왼쪽 메뉴 [정량평가 결과 파일 만들기]에 선생님들이 낸 정량평가 자기평가서(hwpx) 폴더를 넣음
- 파일마다 평가요소별 점수(학습지도·생활지도·전문성개발·담당업무)와 '교사 ○○○ (인)'의 이름을 읽음 (이름이 없으면 파일 이름에서 찾음)
- 기본 세팅의 구분(정규교사·기간제교사)별로 가나다순 표를 만들어 아래에서 미리 보고, [한글 파일 내려받기]로 점수 모음 한글 파일을 받음
  - 양식: `assets/template/moum-template.hwpx` (점수 모음 양식에서 이름·점수를 지운 것)
  - 합계는 양식의 계산식과 같이 학습지도 + 생활지도 + 전문성개발
- 파일이 없는 평가 대상자, 읽지 못한 파일, 두 번 낸 선생님을 알려 줌

## 교과전담교사 과목 정보 (선택)

- [다면평가 기본 세팅] 6번 '교담 정보 추가하기'에 한글 파일(hwpx)을 넣음
- 파일에서 과목 이름만 불러옴 (학년·시수·반 등 다른 정보는 뺌). 과목·교사 칸이 있으면 과목 칸에서, 없으면 평가 대상자 이름이 있는 줄에서 교과 이름을 찾음
- 자기실적평가서 배포 파일에 교과전담 선생님의 담당 과목을 자동으로 채움 (예: 영어, 과학)

## 다면평가자용 엑셀 파일 (선택)

- [다면평가 기본 세팅] 7번에 다면평가자 이름으로 된 엑셀 파일(xlsx)을 구분(정규교사·기간제교사)마다 다면평가자 수만큼 넣음 (여러 개를 한꺼번에)
- 시트 이름이나 파일 이름에 있는 다면평가자 이름으로 누구의 파일인지 찾음
- 정성평가 배포 파일을 만들 때 다면평가자마다 자기 파일(구분별)만 잠근 상자에 넣음
- 다면평가자가 순위를 다 정하고 [최종 점수표] → [엑셀 파일 내려받기]를 누르면, 구분마다 그 구분의 점수를 파일의 '점수오류점검' 시트 태도~담당업무 칸(D~H)에 넣어 차례로 내려받음
  - 이름(C열)이 같은 줄에 넣고 본인 줄은 비워 둠. 나머지 시트·수식·보호는 그대로이고, 열면 엑셀이 다시 계산함
- 파일 내용은 관리자 컴퓨터 브라우저의 IndexedDB에 저장 (크기가 커서)

## 교내 인사 자료 (선택)

- [다면평가 기본 세팅] 4번(학년 정보)·5번(업무 정보)에 교내인사 '부장교사·담임교사·교과전담교사·비교과교사 배정표'와 '업무분장' 한글 파일(hwpx)을 넣음
- 읽는 것: 담임 학년·반, 학년 부장, 업무 부장(교무·연구·생활·안전·체육·지원문화·과학정보), 교과전담, 비교과(특수·영양·보건·사서), 사람마다 맡은 업무
- 정량평가·자기실적평가서 배포 파일에 선생님마다 미리 채움 (생활지도 곤란도, 업무 곤란도 / 담당 학년 및 학급, 담임 여부, 담당 업무, 보직교사 여부). 선생님이 고칠 수 있음

## 정량평가 자기평가서

- 양식: `assets/template/quant-template.hwpx` (2026년 빛여울 정량평가 자기평가서)
- 입력: 주당 수업시간, 수업 공개(학부모 초대 수업·전학공 수업나눔), 학생·학부모 상담 횟수, 생활지도 곤란도(담임 학년 또는 교담·비교과·특수), 연수 이수 시간, 업무 곤란도
- 점수: 양식의 배점 기준대로 자동 계산 (예: 15시간 = 1학점, 상담 51회 이상 10점)
- 고르기: 교담·비교과·특수, 교무·연구·생활부장, 기타 부장(1~6학년·체육·안전·지원문화·과학정보)
- 한글 파일: 고른 배점 칸에 ∨ 표시(양식의 작성 예시와 같은 모양), 실적·평가요소별 점수·총점·이름을 채우고 2쪽 '작성 예시'는 뺌
  - 총점 오른쪽 요약표(이름·학습지도…총점)는 지우고 한 칸으로 합침
  - 확인란에는 기본 세팅의 다면평가자 이름을 '이름(인)'으로 차례로 넣음 (양식 칸은 8개)
- 양식의 줄·칸 위치에 맞춰 채우므로, 내년에 양식의 표 구조가 바뀌면 프로그램도 고쳐야 함

## 점수 만들기 규칙 (엑셀 매크로와 같은 규칙)

- 평가 대상자: 구분별 명단에서 **다면평가자 본인을 빼고** 가나다순
- 등급 인원: 엑셀 '등급인원' 시트 표 (예: 35명 → 수 11·우 14·미 10)
  - 엑셀 표에서 합계가 맞지 않던 1명(0·0·0 → 1·0·0), 61명(18·25·12 → 18·25·18)은 바로잡음
- 총점: 1위는 항상 100점, 수 95.1~99.5점, 우 90.1~94.5점, 미 85.1~89.5점 범위에서 소수 둘째 자리까지 겹치지 않게 뽑아 높은 순으로 순위 칸에 배치
- 항목별 점수: 태도 10%, 학습지도 40%, 생활지도 30%, 전문성 5%를 반올림하고, 담당업무는 총점에서 나머지 (합계가 총점과 꼭 같음)
  - 엑셀 점수 생성기 결과 198줄과 비교해 모두 같은 값이 나옴
- 최종 점수표: 이름 가나다순, 순위는 총점 기준(RANK.EQ), 등급별 행 색(수 연두·우 노랑·미 연보라)
- 항목 배점과 등급별 점수 범위는 위 기본값으로 고정 (관리자 화면에서 바꾸지 않음)

## 보안

| 무엇 | 어떻게 |
|---|---|
| 배포용 파일 | 다면평가자마다 이름으로 만든 열쇠(PBKDF2 60만 번 + AES-GCM)로 잠금, 명단에 없는 이름은 열리지 않음. 사용 기한이 지나면 열리지 않고 입력 내용도 지움 (기한 3일 전부터 알림) |
| 관리자 로그인 | 아이디·비밀번호는 바꾼 값(PBKDF2)만 이 컴퓨터 브라우저에 저장 |
| 배포 파일 접근자 | [회원 관리]에서 아이디·비밀번호로 추가 (접근자 비밀번호는 관리자가 볼 수 있게 관리자 컴퓨터 브라우저에 저장). 배포 파일에 접근자 상자(그 비밀번호로 만든 열쇠로 잠금)를 넣어, [접근자로 들어가기]로 모든 다면평가자·선생님의 처음 화면을 골라 봄 (입력 내용은 각자 컴퓨터에만 있어 보이지 않음) |
| 백업 파일(.phs) | 관리자 로그인 비밀번호로 암호화(PBKDF2 60만 번 + AES-GCM) |
| 자료 저장 위치 | 인터넷 서버로 보내지 않고 각자 컴퓨터의 브라우저 안에만 저장 |
| 저장소 | 엑셀·한글·json 자료 파일은 올리지 않음 (`.gitignore`) |

## 실제 학교에서 쓰는 법

실제 사용 파일은 인터넷에 올리지 않고 컴퓨터에서 바로 엽니다.

```bash
python tools/build_local.py
```

`관리자용 파일/다면평가 편하샘.html` 이 만들어집니다. 라이브러리·아이콘·한글 양식이 모두 들어 있어 인터넷 없이 더블클릭으로 열 수 있습니다.
처음 열면 관리자 계정을 만들고, 다면평가 기본 세팅부터 시작합니다.
